Real-time
WebSockets — two channels
Feed channel
Every user on the feed page holds an open WS connection.

new_post event → card animates in for everyone.
join_update event → count bumps, joiner chip appears for post author.
Chat rooms
Each Connection has its own room. Only the poster + joiner can connect (verified from session).

Messages persist to DB and broadcast to both participants.
class WSManager: feed_clients: list[WebSocket] chat_rooms: dict[int, list[WebSocket]] async def broadcast_post(data): # → all feed viewers # auto-prunes dead sockets async def broadcast_msg(room, msg): # → chat room participants
Client resilience: exponential backoff reconnect (1.5s → 30s), 25s keep-alive ping, input disabled while disconnected.
AI Features — powered by Claude
Four integrations. Zero gimmicks.
01 · Ghost text completion
Types alongside you
Claude streams a post completion in real-time as you type. Tab to accept. Context-aware: knows your category + time of day.
02 · Surprise me
One-click post generation
Claude picks a category AND writes the post based on trending campus activity, time, and day of week.
03 · Chat icebreaker
Kills the awkward "uh hi"
When a new chat opens, Claude generates a natural opening line specific to the activity. One click to send it.
04 · Match scores
Feed that knows you
Posts show a % match badge. Claude scores them against your join history in a single batch call after page load.
